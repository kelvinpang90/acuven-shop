Privacy

This whole site is a demonstration; no real orders are fulfilled.

This site is a demo store. We collect only what is needed to run the demo, and nothing is really paid for or delivered.

What we collect

For orders: recipient name, phone number, country, region, address and postcode. For members: mobile number and, if you set one, a securely hashed password. We do not ask for email or ID documents.

You may use fictional shipping details. The exception is when SMS verification is on: a Malaysian or Singapore mobile number entered at checkout must then be able to receive our verification SMS.

When payments use Stripe test mode, you pay on Stripe's test page instead of ours. We send Stripe only the amount and currency, a demo item name, an internal order reference, your language, the links back to this site and a fixed demo email — not your name, phone number, address or order number. Anything you type on Stripe's page, such as a cardholder name, billing address or a changed email, is kept by Stripe's test environment; we don't read or store it and can't delete it item by item, only the whole test environment. Use only test card numbers and made-up details there.
