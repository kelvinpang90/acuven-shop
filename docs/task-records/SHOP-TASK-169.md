- 请求模块（`api/adminSiteSettings.ts`）：
  - 读取：`AdminSiteSettings` 加 `sms_verification_enabled` 与 `sms_available`，两者都须为布尔值（缺少或类型不对算不合格，归 `failed`），合格时带进结果；多出的字段照旧不带进结果。
  - 保存：`saveAdminSiteSettings(paymentMethod, smsVerificationEnabled, csrfToken, signal?)`，JSON 请求体只有 `payment_method` 与 `sms_verification_enabled` 两项。200 的响应体另要求 `sms_verification_enabled` 为布尔值，`ok` 结果带保存后的两项（新类型 `SavedSiteSettings`）。422 且 `detail` 为 `sms_not_configured` 归新增的 `sms_not_configured`，`stripe_not_configured` 仍归 `not_configured`，其他 422 仍为 `failed`。其余归类、请求头、no-store 与中止处理不变。
- 短信一组（`pages/AdminSiteSettingsPage.tsx`）：标题之下、支付方式一组之前为 `admin.sms_toggle` 一组（fieldset 与 legend 照支付方式一组，另加 `site-admin-settings__sms`；支付方式一组另加 `site-admin-settings__payment`，供测试分别取用），依次为单选 `admin.sms_on`、`admin.sms_off`（同名 `sms_verification_enabled`，值为 `on` / `off`，UX 线框的顺序），其下 `admin.sms_toggle_hint` 与 ★ `admin.sms_toggle_cost`（前面为不读出的菱形标记，照 `AdminOrderDetail.tsx` 的 `DemoMark` 写法），再是现有的支付方式一组与 `common.save`。选中项为读取（或保存成功后返回）的当前值。`sms_available` 为假时开启单选禁用（文字加 `acs-admin__muted`）并以 `aria-describedby` 指向紧接两个单选之后、`admin.sms_toggle_hint` 之前的 `admin.sms_not_configured` 说明（`SMS_NOTE_ID`，照 Stripe 说明的位置与写法）；当前已开启时照常选中，关闭仍可选并可保存。`admin.sms_toggle_cost` 始终显示。不加确认框。
- 保存与被拒：页面状态加 `smsChoice`（短信的选中项）与 `smsRejected`（短信被拒）。点 `common.save` 以两组的当前选择与读取给的 `csrf_token` 调用 `submitSettings(base, choice, smsChoice, signal, moves)`。`ok` 以返回的两项更新两组的选中项与之后保存的依据并显示 `admin.settings_saved`；`sms_not_configured` 在保存按钮下方（与 `admin.settings_saved` 同一位置）显示 `admin.sms_not_configured`（`AdminAlert`，`role="alert"`），两组选中项不变、保留表单，它与开启选项下方的禁用说明是两个独立的元素，可同时出现；`not_configured` 照旧显示 `admin.stripe_not_configured`。改选任何一项（新导出的纯函数 `chooseSms` 与现有的 `chooseMethod`）后收起保存的三种提示；`startSaving` 也收起短信被拒。`none`、`csrf`、`network`、`failed` 与读取的处理不变。传给事件属性的处理函数不返回 Promise。
- 样式（`site.css`）：短信一组与选项沿用支付方式一组现有的 `site-admin-settings__group` 与 `site-admin-settings__option`；新增 `site-admin-settings__cost`（标记与文字同一行，间距 8px，内边距 8px 10px，标记不收缩、上边距 2px），照视觉稿 A09-stripe-desktop / A09-stripe-phone 的费用提示。手机上与桌面相同，没有另写 767px 及以下的差异。未声明颜色、字体与圆角属性。
