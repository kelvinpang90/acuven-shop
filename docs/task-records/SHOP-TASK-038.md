- 文件结构（全部在 `frontend/src/`）：
  - `router.tsx`：路由表加 `/admin/login`（在 `/privacy` 之后），注释写明后台页的凭据只在页面内存与请求里、App 不给后台页套前台框架、前台没有指向它的入口。`App.tsx`：页面表加入 `AdminLoginPage`；当前路由以 `/admin` 开头时直接渲染页面，其余路由照旧放在 `SiteFrame` 里。`components/SiteFrame.tsx` 未改：页头、菜单与页脚的入口本来就是写死的前台列表，不含任何 `/admin` 路径。

  - `pages/AdminLoginPage.tsx`（新）：`AdminLoginView` 为可单独渲染的展示部分，`AdminLoginPage` 接上状态与请求；导出的纯逻辑 `watchColorScheme`（深浅色）、`canLogIn`、`LOGIN_ERROR`、`sessionState`、`logIn`、`beginLogIn`（先清空密码框再登录）、`logOut`。

- 页面状态：
  - 根元素 `acs-admin`（另带布局用的 `site-admin-login`），`data-mode` 首次渲染为 `light`（服务端渲染与首次客户端渲染都是），挂载后按 `matchMedia("(prefers-color-scheme: dark)")` 设为 `light` 或 `dark` 并随设备设置变化；没有 `matchMedia` 时保持浅色。界面语言沿用 `LanguageProvider`（默认英文）。
  - 首次渲染（会话请求未返回）：`acs-admin__banner` 里 `common.demo_badge` 标签与 `admin.demo_banner`；面板里 `admin.login_title` 与语言切换；主体标 `aria-busy`，没有表单与已登录内容。语言切换两种都渲染：桌面为 `acs-admin__lang` 里三种语言的站内链接（指向本页，当前语言 `aria-current="true"`，点击只切换语言）；手机为 `acs-admin__btn acs-admin__btn--secondary` 按钮，文字是当前语言名称（可访问名称就是它，没有另加 `aria-label`），点开后在标题行之下展开同样沿用 `acs-admin__lang` 的三种语言链接，选择后收起。由 `site.css` 按宽度只显示其一。
  - 登录表单：`acs-admin__field` 标签里的 `admin.username`（`autocomplete="username"`）与 `auth.password`（`type="password"`、`autocomplete="current-password"`）、`auth.login_submit` 按钮；表单 `method="post"`、`noValidate`，输入框不设 `name`、不标 `required`。错误提示为 `acs-admin__alert`（`role="alert"`），在提交按钮之后。
  - 已登录（过渡规则）：面板保留标题与语言切换，其下 `admin.logged_in`（`{username}` 为会话接口返回的用户名）与 `admin.logout` 按钮（`acs-admin__btn acs-admin__btn--secondary`），没有表单；退出的提示在按钮之后。
- 请求与错误处理：
  - 打开时 `GET /api/admin/session`：200 已登录，401 登录表单，其他结果（含网络中断与不合格的响应体）登录表单与 `common.error_retry`。离开页面时中止，之后不再更新页面。
  - 登录：用户名或密码任一为空、或请求进行中时提交按钮禁用（只判断空串，内容原样提交，由服务端规范化）。提交时先清空密码框、保留用户名，再以提交时的值 `POST /api/admin/login`。204 后再 `GET /api/admin/session` 并显示已登录状态；401 `admin.login_failed`，429 `admin.locked`，503 `common.service_unavailable`，网络中断 `common.network_check`，其他（含 204 以外的 2xx）`common.error_retry`。
  - 退出：`POST /api/admin/logout` 带当前会话的 `X-CSRF-Token`，进行中按钮禁用。204 或 401 回到登录表单（用户名保留、密码框为空）；403 重新取会话：取到时按新会话（新令牌）保持已登录，401 时回到登录表单，都显示 `common.error_retry`；网络中断 `common.network_check`，其他结果 `common.error_retry`，都保持已登录状态。
  - 用户名与密码只在 React 状态与登录请求体里，CSRF 令牌只在 React 状态与退出请求头里；都不写 localStorage、sessionStorage、cookie 或历史记录，不进任何路径或查询参数，错误提示只用字典文案，不含用户名或密码。
