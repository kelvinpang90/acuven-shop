- 请求（`api/adminRefunds.ts`）：
  - `parseRefundId`：路径里的 ID 只接受不带符号与前导零、不超过 `MAX_REFUND_ID`（2147483647，与 SHOP-TASK-041 记录段相同）的十进制正整数；不合格时 `readAdminRefund` 归为 `missing`、`reviewAdminRefund` 归为 `failed`，都不发请求。
  - `readAdminRefund`：`GET /api/admin/refunds/{内部 ID}?lang=<界面语言>`，同源 cookie、`cache: "no-store"`、带中止用的 signal。只取 SHOP-TASK-041 记录段列出的字段（`id`、`status`、`created_at`、`reviewed_at`、`reviewer_username`、`review_reason`、`order_id`、`order_number`、`order_status`、`amount_sen`、`lines` 每行五个字段、`refunded_sen`、`refundable_left_sen`、`csrf_token`），多出的字段不带进结果；时间沿用列表对 `created_at` 的写法，金额与已批准件数须为非负整数、申请与购买件数为正整数，`order_status` 为六种订单状态之一；审核中的申请 `reviewed_at` 与 `reviewer_username` 须为 null，已批准或已拒绝的两者须有值；任一项不合格算失败。归为 `ok`、`none`（401）、`missing`（404）、`failed`（其他）与 `network`。
  - `reviewAdminRefund`：`POST /api/admin/refunds/{内部 ID}/approve` 或 `/reject`，JSON 请求体只有 `reason`（输入框原文，去掉首尾空白由服务端负责），请求头 `Idempotency-Key` 与 `X-CSRF-Token`（沿用 `api/pay.ts` 的 `IDEMPOTENCY_HEADER`、`CSRF_HEADER`；令牌取详情返回值），同源 cookie、`cache: "no-store"`。归为 `done`（200）、`reviewed`（409 `refund_already_reviewed`）、`conflict`（409 `idempotency_conflict`）、`csrf`（403）、`invalid`（422）、`none`（401）、`failed`（其他，含别的 409 与 404）与 `network`。
- 审核与幂等（`pages/AdminRefundDetail.tsx`）：
  - 审核中依次为内容面板里的 `admin.refund_reason` 输入框（`textarea`，`maxLength` 500），面板之后的 `admin.refund_approve`（主按钮）、`admin.refund_reject`（次要按钮）、提示与 ◆ `admin.refund_hint`（◆ 以 `aria-hidden` 标出）。`canReview`：理由去掉首尾空白后为空时拒绝禁用，批准不要求理由；进行中两个按钮与输入框都禁用。
  - 幂等键（`reviewAttempt`）：每次新的审核以 `crypto.randomUUID` 生成；网络中断后保留这次的操作、理由与键（`useRef`），再点且操作与理由都没变时沿用同一个键，改了理由或操作即换新；得到确定回答（200、两种 409、403、422、401 与其他失败）后丢弃（`keptAttempt`）。
  - 结果（`submitReview` 与 `reviewStep`）：200 后让左侧列表按同一查询重新查询（列表区标 `aria-busy`、保留原来的行），并重新取详情；409 `refund_already_reviewed` 与 403 重新取详情并显示 `common.error_retry`；409 `idempotency_conflict`、422 与其他失败显示 `common.error_retry`，不重新读取；网络中断显示 `common.network_check`，不重新读取；401（审核或重新读取）用路由的 `replace` 进入 `/admin/login`。提示为 `AdminAlert`，在按钮之后。
- 已审核只读：已批准或已拒绝时不显示理由输入框、审核按钮与 `admin.refund_hint`；内容面板里金额之后为 `admin.reviewed_by`（`{username}` 为 `reviewer_username`，即管理员邮箱，只在已登录管理员的页面内存与页面上；`{time}` 为 `reviewed_at` 经 `TrackOrderPage.tsx` 的 `formatDateTime`），有理由时其下为 `admin.refund_reason`（`acs-admin__muted`）与理由原文（保留换行），没有理由时不显示这两行。
