- [x] 新增 `app/api/admin_store_logo.py`（路由类为 SHOP-TASK-027 的 `_NoStoreRoute`，处理函数与依赖产生的全部响应都带 `Cache-Control: no-store`），在 `app/main.py` 注册：
  - `PUT /api/admin/store-design/logo`（上传），检查依次为，前一项不通过即回答、不再往下：`require_admin`（401 `admin_session_required`）→ X-CSRF-Token（403 `csrf_failed`，沿用 `admin_products` 的 `CsrfDep`）→ `image_store_configured` 为 False 即 503 `image_store_unavailable`、不读请求体 → Content-Type 去掉分号后的参数与首尾空白、转小写后不是 `image/jpeg`、`image/png`、`image/webp` 之一即 415 `image_type_unsupported` → 请求头声明的长度超过 5,242,880 即 413 `image_too_large`、不读请求体 → 最后声明的异步依赖逐块读取，读到超过即停止并 413 → `process_image(data, min_side=LOGO_MIN_SIDE, min_long_side=LOGO_MIN_LONG_SIDE)` 抛 `ImageRejected` 即 422 `logo_invalid` → `replace_logo` 抛 `ImageStoreUnavailable` 即 503 `image_store_unavailable`。没有张数上限这一项。
  - `DELETE /api/admin/store-design/logo`（移除）：`require_admin`（401）→ CSRF（403）；不读请求体 → `remove_logo`（没有标志时照样成功、不写审计；存储未配置时照常清空，服务层只记日志）。
  - 两个处理函数都是同步函数，FastAPI 在线程池里执行；只有读请求体的依赖是异步的。不写日志（服务层与存储模块自己的日志除外）。
