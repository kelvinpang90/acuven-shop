- [x] 页面（`frontend/src/pages/AdminProductsPage.tsx`，写法照 SHOP-TASK-202、203、`AdminShippingPage.tsx` 与 `AdminCategoriesPage.tsx`）：
  - 状态：`Editing` 的 `ready` 另有 `saving` 与 `notice`（`SaveNotice`：`admin.product_saved`、`admin.product_invalid`、`admin.product_changed`、`common.network_check`、`common.error_retry`）；`editorOf` 给出 `saving: false`、`notice: null`。改任何输入（`withForm`，即 203 的全部改动函数）都收起 `notice`；只切换内容语言不收起。
  - 页面先查（导出的纯函数）：`priceSen`（调用 `AdminShippingPage.tsx` 的 `feeSen`，即 `FEE_PATTERN` 与整数部分乘 100 加补足两位的小数部分，再要求不超过 `MAX_PRICE_SEN` = 50,000,000）、`stockCount`（1–4 位数字）、`limitCount`（1–4 位数字且 1–1000）、`publishReady`（英文名称、英文描述、全部规格名与规格值的英文名称去掉首尾空白后都不为空，且至少一个 SKU 勾选启用）。
  - 请求体（导出的纯函数）：`saveInput(form, version)` 组成 SHOP-TASK-200 的 `ProductSave`——version、文案原样、所选分类 ID、上架、每单限购、全部规格名与规格值（id 与三语名称，按读取的顺序）与全部 SKU（id、价格整仙、每日初始库存与启用，按读取的顺序，不带规格值组合）；价格、库存或限购任一不合格，或勾选上架而 `publishReady` 不满足时为 null。
  - 结果变成页面状态（导出的纯函数）：`saveStep(write, id)`——ok 时编辑区为 `editorOf(id, 返回的商品)`（新的基线与 version，内容语言不变）并显示 `admin.product_saved`，列表该行照 `savedItem` 更新；none 为 `login`；csrf 为 `reread`；invalid、changed、network、failed 各为对应提示、保留已填的值。`rereadStep(products, categories, id)`——403 后重新读取列表与分类：都取到时换成新列表、新分类与新 CSRF 令牌，编辑区与已填的值、`product`（即提交前的 version）保留，提示 `common.error_retry`；任一 none 为 `login`；否则 network 为 `common.network_check`、其他为 `common.error_retry`，列表、编辑区与旧令牌不变。`savedItem` 的名称与状态取自返回的商品，分类名称取自分类读取的结果。结果只改仍在保存的同一件的编辑区（内部 `withSavingEditor`：同一 id 且 `saving`），列表照样更新。`startSaving` 禁用按钮并收起提示。
  - 异步函数：`submitProduct(csrfToken, editor, signal, moves)`（先 `saveInput`，为 null 时不发请求、显示 `admin.product_invalid`；否则 `saveAdminProduct`，403 时再并行读取列表与分类）；`reloadProducts(id, signal, moves)`（先显示读取中，并行读取列表与分类，取到后编辑区为读取中，再 `openProduct` 读取同一商品；整页读取 none 回到 A01、其他失败只有提示）。
  - View：编辑区面板改为 `form`（203 记录里说明的那一处），提交时 `onSave`；最后为 `SaveArea`：`common.save`（type=submit，保存中 `disabled` 并 `aria-busy`），其下 `admin.product_saved` 为 `role="status"`，`admin.product_changed` 为带次要按钮 `admin.reload` 的 alert，其余为 `AdminAlert`。`AdminProductsViewProps` 另有 `onSave` 与 `onReload`。
  - 容器：新增页面级的 `lifetime` 中止（打开页面与保存共用，离开页面时中止）；`onSave` 在已取到且未在保存时 `startSaving` 后调用 `submitProduct`（令牌为列表读取给的 `state.csrfToken`）；`onReload` 不经未保存确认（UX「点「已被改动」提示里的 [admin.reload] 是明确放弃修改，不再确认」），中止前一次单件读取后调用 `reloadProducts`。传给事件属性的处理函数都不返回 Promise。
- [x] 样式：`frontend/src/styles/site.css` 在 203 的 `.site-admin-products__notes` 之后加入 `.site-admin-products__save`（grid，间距 10px，`common.save` 靠左，成功提示内边距 10px 12px）与 `.site-admin-products__changed`（文字与 `admin.reload` 上下排列、间距 10px、靠左），767px 及以下的媒体查询里 `common.save` 占满宽度、文字居中、至少 44px 高，`admin.reload` 至少 44px 高（照 A04-phone-edit 与 A10 的写法）。没有声明颜色、字体与圆角，未改 `acuven-shop.css`。
